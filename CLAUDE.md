## Key paths

- Papyrus: `Scripts/Source/` → `Scripts/`; project `skyrimse.ppj` (compile: pyro).
- SKSE plugin: `SKSE_Source/` → `make dll` → `SKSE/Plugins/SkyrimNet_Whipped.dll`. Natives: `SkyrimNet_Whipped_Engine.psc`.
- ESP source of truth: `Spriggit/SkyrimNet_Whipped/` → `make esp`. Never hand-edit `SkyrimNet_Whipped.esp`; after xEdit edits run `make serialize`.
- Injury data (all wound / healing numbers and text): `SKSE/Plugins/SkyrimNet_Whipped/injuries/*.json`, guide for editing them: `injuries/guide.md`.
- LLM content: `SKSE/Plugins/SkyrimNet/external/goodprovider.whipped/` (folder name = manifest `id`).
- Dashboard settings: `SKSE/Plugins/SkyrimNet/config/plugins/SkyrimNet_Whipped/manifest.yaml`, read as `Plugin_SkyrimNet_Whipped`.

## Flow

Real weapon hit → ENCH → `SkyrimNet_Whipped_LashEffect.OnEffectStart` → `Main.OnLash`.
LLM action `Torture_Target` (registered in Papyrus; params target, type `whip|pinch|slap|pull|punch`, strikes) → whip: `Main.Lash` (PlayImpactEffect + sound) → `Main.OnLash`; other types: `Main.Torture` (optional `action.animation`) → `Engine.Hit`. Part names and source ids from Papyrus match case-insensitively (`InjuryConfig::IEquals`). `Main.External_Torture` is the API for any torture type (`External_Strike` stays whipping only). The `skyrimnet_whipped.in_action` StorageUtil flag stops double counting.
Injury data and text: `SKSE/Plugins/SkyrimNet_Whipped/injuries/<source>.json` (torture: `whipping`, `pinching`, `slapping`, `pulling`, `punching`, `fire`, `frost`, `shock`; health: `slashing`, `piercing`, `bludgeoning`, `burning`, `freezing`, `shocking`, `mauling`, `generic`; sexual assault later) loaded by `InjuryConfig` at kDataLoaded; the schema and an agent guide for improving them are in `injuries/guide.md`. Nothing about wounds is hard-coded any more: stage thresholds, part and region names, narration prose, healing text, bio / feels tables, Whip_Target text, overlay title and colors, setting defaults all live in those files (`manifest.yaml` still carries the dashboard schema and mirrors the defaults).
`InjuryEngine` (C++, co-saved version 4; versions 2 and 3 with whipping only still load) tracks injury per actor, per body part, per source. Torture (model `torture`) is one deficit per (type, part) (`healing_max+1..+part max` damage, `1..healing_max` healing, 0 healed); a part counts only its largest type (health hold, overlay); healing a part lowers every type by one; real damage replacing torture lowers the part's maximum by one and clamps every type to it. Types land by their JSON `part_weights`. Parts: 6 main (face, arms, back, legs) plus, with setting `whip.body.include_sexual_parts` (off by default, `SetIncludeSexualParts`), 5 small ones (nipples, pussy (women only), penis (men only), lips, ass hole) defined with their text in `injuries/sexual_parts.json` (not a source; its `text.<source id>` blocks are merged into each source's region text). Each part has its own max points and pick weight; medium / severe thresholds scale with the max; health capacity is the sum of the actor's active parts. Off: no new wounds there and hidden from prompts / overlay, existing ones keep healing. Hit code `fresh*100000000 + source*1000000 + mask*10 + level`, heal code `source*128 + part*8 + stage`. Model `torture`: `OnLash` calls `SkyrimNet_Whipped_Engine.Hit(victim, "whipping")` (random body part, damage then healing over game time); whipping requires a SkyrimNet_Whipped whip. `Classifier` maps unarmed NPC hits by an attacker out of combat to `punching` and the "(torture)" spell effects (MGEF 0x813–0x815, matched by form, in or out of combat; vanilla Flames / Frostbite / Sparks stay real damage) to `fire` / `frost` / `shock` (hit event, attacker, or an active-effect scan for spell ticks); `OnDamage` then blocks the game damage and turns it into torture hits (melee one hit, spells one per `hook.hit_share` of max health). Model `health` (everything else): `Hooks.cpp` hooks `Actor::HandleHealthDamage` (SE / AE) and `ActorValueOwner::ModActorValue` (kDamage on Health) on Character and PlayerCharacter, `Classifier` picks the source (TESHitEvent + the attacker's weapon: blades slashing, daggers and arrows piercing, maces / staves / fists bludgeoning, spell resist fire / frost / shock burning / freezing / shocking, creature attacks mauling, else `generic`; Padded Whip hits ignored) and `InjuryEngine::OnDamage` turns the health the attack takes into points (capacity 6 parts × 20 = 100% of max health, one location per attack: a weighted random part, whipped parts first; the attack stays on that part until it is full, then moves to another random part, whipped first). Real damage first replaces the whip points on its part (the hook reduces the damage so health does not drop by that part, whip points there are removed and the same health worth of real points added on the same part) and only then takes health, so a whipped actor dies only after the whip wounds are replaced (a hit big enough to fill its part can take some health first); the 10% floor applies only while whip points exist. The hook queues the hit and fires mod event `SkyrimNet_Whipped_Injury`, which makes `Main.OnInjury` start the sync loop; `Main.NarrateRealHits` drains `TakeHits` and narrates through the same `NarrateInjury`.
`NarrateInjury` sends each non-whip hit as one `RegisterShortLivedEvent` `injury_hit` (never narrated, no batch, no cooldown change). Torture hits form one scene of (attacker, victim) pairs (StorageUtil parallel lists `KEY_SC_*` on the Main quest; no attacker = the quest itself): `SceneTick` (from `OnUpdate`) sends combined lines from `Engine.SceneText` (`session.json` + each source's `narration.session`): `start` for new pairs only, `again` every `torture_direct_narration_gap` (6 s), `switch` when a pair changes method, `end` once a pair's last hit is `torture_maximum_break` (3 s) old; same method / mixed methods and several attackers or victims are worded into one line. The player is attacker or victim: `PurgeDialogue(true)` + DirectNarration, else `OptionalDirectNarrate` (DirectNarration if the speech queue is empty, else a short-lived event); narration off: events. Only pairs in sight (`PairVisible`) are narrated; an out of sight pair ends with `RegisterPersistentEvent`. Hits between lines are short-lived `torture_hit` events with a stable id per (attacker, victim) pair (`TortureHitEventId`; re-register overwrites and refreshes TTL). `Torture_Target` just lands its strikes through the scene. `whip.narration.cooldown` gates healing only. Healing mirrors hitting: `TakeHealedActors`/`TakeHealed` return heal codes (a part reached a new stage, a source healed on every part it touched, a part with no injury left from any source; transient C++ queue, filled by game time for whip points and by health conversion for all), drained by `OnUpdateGameTime` and every `OnUpdate` tick. Passive heal codes (`+100000`: healed by game time or natural regen, no healing source) are recorded silently (dropped while the victim's last torture hit is within `torture_narration_window_size`, `InTortureSession`, so a punishment is not called "nothing to remark on" seconds later): one `RegisterShortLivedEvent` `whip_heal_passive_*` per take, text wrapped in `narration.heal.passive` (ordinary healing, nothing to remark on), no batch or cooldown change. `NarrateHealing` batches the rest per victim (StorageUtil `skyrimnet_whipped.heal_*`): the first heal since the last hit always narrates (a short-lived event if narration is off or too far); later ones send one combined DirectNarration when the gate allows, otherwise a RegisterShortLivedEvent `whip_heal_*` per take; a new hit clears the heal batch. Health link: whip wounds hold health down by deficit (damage + missing healing points) × `0.9 × MaxHealth / 186`, real points by `MaxHealth / 120` each; the wounded level is `max − both`, never below 10% max while whip points exist. `Main.OnUpdate` runs every 0.2 s while `TrackedCount() > 0`, calling `SyncHealth`: health above the wounded level converts back to points (random whip / real point, random part, damage first), fully while a healing source is active or the actor has no whip wounds, otherwise natural regen at `whip.healing.regen_rate`% (the rest is taken back). Healing sources come from a `MagicTarget::AddTarget` vtable hook (`Hooks.cpp`) plus an active-effect scan; events (heal start, pain gone, fully healed, heal stopped) carry source kind + caster and are narrated by `Main.NarrateSourceHeal`: with no healing source (pain gone / fully healed by natural healing) a silent `RegisterShortLivedEvent` wrapped in `narration.heal.passive` (none within the torture window); otherwise fully healed is always a DirectNarration (while narration is on) and clears the heal batch; start, pain gone and stopped go through the usual gate or a short-lived `whip_heal` event. Every event is a `RegisterShortLivedEvent` (expires after `whip.narration.event_ttl`); only narrations are permanent. Setting `whip.healing.give_healing_hands` adds Healing Hands (Skyrim.esm 0x4D3F2) to the player.
Narration text is rendered in C++ from the JSON files (`InjuryEngine::HitText`, `HealText`, `SourceHealText`, `ActionText`, natives of the same names), no prompt is involved. Prompt text for the LLM: `character_bio/0420_injury_looks.prompt` and `user_final_instructions/0420_injury_feels.prompt` loop over decorator `skyrimnet_whipped_injuries(uuid)` (`Main.Injuries_Decorator`, `GetStateJson`), whose `look` / `feel` strings are already resolved for the actor.
Verbose logging (`whip.debug.verbose_logging`, off by default): `ApplyPluginConfig` passes it to `SetVerboseLogging` (spdlog `debug` level in `SkyrimNet_Whipped.log`) and gates `Main.Verbose` / `[v]` traces in `Papyrus.0.log`; costly messages sit inside `if verbose_logging`.

Overlay (`whip.overlay.enabled`, "Show whipping overlay"): PrismaUI view `PrismaUI/views/SkyrimNet_Whipped/overlay.html`, created by `Overlay::Init` on kDataLoaded (`Overlay.cpp`, header vendored in `SKSE_Source/lib/PrismaUI/`). The Papyrus natives `Hit`, `SyncHealth`, `TakeHealedActors`, `TakeHits` and `Forget` call `Overlay::Notify`, which pushes `InjuryEngine::OverlayJson` to `whipUpdate()` when it changes. `#WhippedPanel` shows a white "Whip Damage" title above `.actor-whipped-damage-bars`: one name-only bar per whipped actor, most recently hit first (whole-body whip damage total, or healing progress once no damage is left; color = average stage); real damage that replaces whip damage grows a darker red segment from the left; an actor whose whip damage is fully replaced is dropped and the panel hides when no actor has whip damage; the whole overlay fades 3 s after the last change.
