SkyrimNet_Whipped: standalone torture damage (whipping, pinching, slapping, pulling, punching, companion fire / frost / shock) and a padded whip for SkyrimNet, modeled on `../SkyrimNet_SexLab`.

## Key paths

- Papyrus: `Scripts/Source/` → `Scripts/`; project `skyrimse.ppj` (compile: pyro).
- SKSE plugin: `SKSE_Source/` → `make dll` → `SKSE/Plugins/SkyrimNet_Whipped.dll`. Natives: `SkyrimNet_Whipped_Engine.psc`.
- ESP source of truth: `Spriggit/SkyrimNet_Whipped/` → `make esp`. Never hand-edit `SkyrimNet_Whipped.esp`; after xEdit edits run `make serialize`.
- Injury data (all wound / healing numbers and text): `SKSE/Plugins/SkyrimNet_Whipped/injuries/*.json`, guide for editing them: `injuries/guide.md`.
- LLM content: `SKSE/Plugins/SkyrimNet/external/goodprovider.whipped/` (folder name = manifest `id`).
- Dashboard settings: `SKSE/Plugins/SkyrimNet/config/plugins/SkyrimNet_Whipped/manifest.yaml`, read as `Plugin_SkyrimNet_Whipped`.

## Flow

Real weapon hit → ENCH → `SkyrimNet_Whipped_LashEffect.OnEffectStart` → `Main.OnLash`.
LLM action `Torture_Target` (registered in Papyrus; params target, type `whip|pinch|slap|pull|punch`, strikes) → whip: `Main.Lash` (PlayImpactEffect + sound) → `Main.OnLash`; other types: `Main.Torture` (optional `action.animation`) → `Engine.Hit`. Part names and source ids from Papyrus match case-insensitively (`InjuryConfig::IEquals`). `Main.External_Torture` is the API for any torture type (`External_Strike` stays whipping only). The `skyrimnet_whipped.in_action` StorageUtil flag stops double counting.
Injury data and text: `SKSE/Plugins/SkyrimNet_Whipped/injuries/<source>.json` (torture: `whipping`, `pinching`, `slapping`, `pulling`, `punching`, `fire`, `frost`, `shock`; health: `slashing`, `piercing`, `bludgeoning`, `burning`, `freezing`, `shocking`, `mauling`, `generic`; sexual assault later) loaded by `InjuryConfig` at kDataLoaded; the schema and an agent guide for improving them are in `injuries/guide.md`. Nothing about wounds is hard-coded any more: stage thresholds, part and region names, narration prose, healing text, bio / feels tables, Whip_Target text, overlay title and colors, setting defaults all live in those files (`manifest.yaml` still carries the dashboard schema and mirrors the defaults).
`InjuryEngine` (C++, co-saved version 4; versions 2 and 3 with whipping only still load) tracks injury per actor, per body part, per source. Torture (model `torture`) is one deficit per (type, part) (`healing_max+1..+part max` damage, `1..healing_max` healing, 0 healed); a part counts only its largest type (health hold, overlay); healing a part lowers every type by one; real damage replacing torture lowers the part's maximum by one and clamps every type to it. Types land by their JSON `part_weights`. Parts: 6 main (face, arms, back, legs) plus, with setting `whip.body.include_sexual_parts` (off by default, `SetIncludeSexualParts`), 5 small ones (nipples, pussy (women only), penis (men only), lips, ass hole) defined with their text in `injuries/sexual_parts.json` (not a source; its `text.<source id>` blocks are merged into each source's region text). Each part has its own max points and pick weight; medium / severe thresholds scale with the max; health capacity is the sum of the actor's active parts. Off: no new wounds there and hidden from prompts / overlay, existing ones keep healing. Hit code `fresh*100000000 + source*1000000 + mask*10 + level`, heal code `source*128 + part*8 + stage`. Model `torture`: `OnLash` calls `SkyrimNet_Whipped_Engine.Hit(victim, "whipping")` (random body part, damage then healing over game time); whipping requires a SkyrimNet_Whipped whip. `Classifier` maps unarmed NPC hits by an attacker out of combat to `punching` and the "(torture)" spell effects (MGEF 0x813–0x815, matched by form, in or out of combat; vanilla Flames / Frostbite / Sparks stay real damage) to `fire` / `frost` / `shock` (hit event, attacker, or an active-effect scan for spell ticks; only an equipped weapon makes a hit melee, an equipped spell ticks per `points_per_second`); `OnDamage` then blocks the game damage and turns it into torture hits (melee one hit, spells `hook.points_per_second` points per real second, melee and lashes `hook.points_per_hit` points on one part). Model `health` (everything else): `Hooks.cpp` hooks `Actor::HandleHealthDamage` (SE / AE) and `ActorValueOwner::ModActorValue` (kDamage on Health) on Character and PlayerCharacter, `Classifier` picks the source (TESHitEvent + the attacker's weapon: blades slashing, daggers and arrows piercing, maces / staves / fists bludgeoning, spell resist fire / frost / shock burning / freezing / shocking, creature attacks mauling, else `generic`; Padded Whip hits ignored) and `InjuryEngine::OnDamage` turns the health the attack takes into points (capacity 6 parts × 20 = 100% of max health, one location per attack: a weighted random part, whipped parts first; the attack stays on that part until it is full, then moves to another random part, whipped first). Real damage first replaces the whip points on its part (the hook reduces the damage so health does not drop by that part, whip points there are removed and the same health worth of real points added on the same part) and only then takes health, so a whipped actor dies only after the whip wounds are replaced (a hit big enough to fill its part can take some health first); the 10% floor applies only while whip points exist. The hook queues the hit (queued hits of one victim, attacker and source merge, and `TakeHits` releases one per key per second; a health hit also releases that victim's held hits; scripted strikes use `QueueHit` so they are gated too) and fires mod event `SkyrimNet_Whipped_Injury`, which makes `Main.OnInjury` drain queued hits, heals, and sync events immediately (`DrainInjuryQueues`: `TakeHits`, `TakeQueuedHealActors`, `TakeSyncEvents`) then schedule the 0.2 s sync loop without resetting an already-pending update (`sync_pending`). `Main.NarrateRealHits` also runs on `OnUpdate` and narrates through `NarrateInjury`.
`NarrateInjury` registers a short-lived event on every hit as soon as the text exists (`injury_hit` / `torture_hit` types; id `health_<method>_<attacker>_to_<victim>` or `torturing_<method>_…`, re-register overwrites TTL). Torture hits also form one scene of (attacker, victim) pairs (StorageUtil parallel lists `KEY_SC_*` on the Main quest; no attacker = the quest itself): `SceneTick` (from `OnUpdate`) sends combined lines from `Engine.SceneText` (`session.json` + each source's `narration.session`): `start` for new pairs only, `again` every `torture_direct_narration_gap` (6 s) but only while the pair's last hit is at most `torture_again_recent` (1 s) old, `switch` when a pair changes method; after `torture_maximum_break` (3 s) with no hit the pair is dropped with no line; same method / mixed methods and several attackers or victims are worded into one line. The player is attacker or victim: `PurgeDialogue(true)` + DirectNarration, else `OptionalDirectNarrate` (DirectNarration if the speech queue is empty, else a short-lived event with the same id); narration off: events. Only pairs in sight (`PairVisible`) get combined start / again / switch lines. `Torture_Target` just lands its strikes through the scene. `whip.narration.cooldown` no longer gates narration (heal sessions use the torture gap). Healing mirrors hitting: `TakeHealedActors`/`TakeHealed` return heal codes (a part reached a new stage, a source healed on every part it touched, a part with no injury left from any source; transient C++ queue, filled by game time for whip points and by health conversion for all), drained by `OnUpdateGameTime` and every `OnUpdate` tick; `TakeQueuedHealActors` takes already-queued heals without applying game time (used from `OnInjury`). Every heal registers a short-lived `whip_heal` immediately (id `healing_<method>_<caster>_to_<victim>`). Healing from a source mirrors the torture scene: one heal session per healed actor (StorageUtil parallel lists `KEY_HS_*` on the Main quest; caster or the quest itself). Heal start (`NarrateSourceHeal`) or the first source heal code (`NarrateHealing`) opens it with an immediate `start` line; later heal codes collect in `skyrimnet_whipped.heal_pending` and `HealTick` (from `OnUpdate`) sends one combined line every `torture_direct_narration_gap`; pain gone joins the next line; fully healed / heal stopped (or no healing for `torture_narration_window_size`) sends the `end` line with whatever is pending. `HealSend` delivers like `SceneSend`: player caster or target: `PurgeDialogue(true)` + DirectNarration, else DirectNarration if the speech queue is empty, else a short-lived event with the same healing id; narration off: that event; out of sight: no start / periodic lines, the end is a `RegisterPersistentEvent`. Sessions are exclusive per victim: a different activity closes the open one silently and starts its own as normal (a torture or real hit: `ClearHealBatch` drops pending heals and closes the heal session; a heal session opening or a real (non-torture) hit: `ClearTortureScene` drops the victim's torture pairs; real damage has no session of its own). Every event is a `RegisterShortLivedEvent` (expires after `whip.narration.event_ttl`); only narrations are permanent. Setting `whip.healing.give_healing_hands` adds Healing Hands (Skyrim.esm 0x4D3F2) to the player.
Narration text is rendered in C++ from the JSON files (`InjuryEngine::HitText`, `HealText`, `SourceHealText`, `ActionText`, natives of the same names), no prompt is involved. Prompt text for the LLM: `character_bio/0420_injury_looks.prompt` and `user_final_instructions/0420_injury_feels.prompt` loop over decorator `skyrimnet_whipped_injuries(uuid)` (`Main.Injuries_Decorator`, `GetStateJson`), whose `look` / `feel` strings are already resolved for the actor.
Verbose logging (`whip.debug.verbose_logging`, off by default): `ApplyPluginConfig` passes it to `SetVerboseLogging` (spdlog `debug` level in `SkyrimNet_Whipped.log`) and gates `Main.Verbose` / `[v]` traces in `Papyrus.0.log`; costly messages sit inside `if verbose_logging`.

Overlay (`whip.overlay.enabled`, "Show whipping overlay"): PrismaUI view `PrismaUI/views/SkyrimNet_Whipped/overlay.html`, created by `Overlay::Init` on kDataLoaded (`Overlay.cpp`, header vendored in `SKSE_Source/lib/PrismaUI/`). The Papyrus natives `Hit`, `SyncHealth`, `TakeHealedActors`, `TakeHits` and `Forget` call `Overlay::Notify`, which pushes `InjuryEngine::OverlayJson` to `whipUpdate()` when it changes. `#WhippedPanel` shows a white "Whip Damage" title above `.actor-whipped-damage-bars`: one name-only bar per whipped actor, most recently hit first (whole-body whip damage total, or healing progress once no damage is left; color = average stage); real damage that replaces whip damage grows a darker red segment from the left; an actor whose whip damage is fully replaced is dropped and the panel hides when no actor has whip damage; the whole overlay fades 3 s after the last change.
