# CLAUDE.md

Injury_Engine: per-body-part injury tracking for SkyrimNet. Real damage is classified by type (slashing, piercing, bludgeoning, burning, freezing, shocking, mauling, falling, generic, plus types from other mods), alongside torture damage (whipping, pinching, slapping, pulling, punching, companion fire / frost / shock) and a padded whip. Modeled on `../SkyrimNet_SexLab`.

**Primary agent doc:** [AGENTS.md](AGENTS.md) (logs, docs map, standing rules, safety, confidence). Imported below so it is always loaded:

@AGENTS.md

## Key paths

- Papyrus: `Scripts/Source/` → `Scripts/`; VS Code task `compile: papyrus` (`.vscode/tasks.json`, `papyrus.exe`).
- SKSE plugin: `SKSE_Source/` → `make dll` → `SKSE/Plugins/Injury_Engine.dll`. Natives: `Injury_Engine_Engine.psc`.
- ESP source of truth: `Spriggit/Injury_Engine/` → `make esp`. Never hand-edit `Injury_Engine.esp`; after xEdit edits run `make serialize`.
- Injury data (all wound / healing numbers and text): `SKSE/Plugins/Injury_Engine/injuries/*.json`, guide for editing them: `injuries/guide.md`.
- LLM content: `SKSE/Plugins/SkyrimNet/external/goodprovider.injuryengine/` (folder name = manifest `id`).
- Dashboard settings: `SKSE/Plugins/SkyrimNet/config/plugins/Injury_Engine/manifest.yaml`, read as `Plugin_Injury_Engine`.

## Flow

Real weapon hit → ENCH → `Injury_Engine_LashEffect.OnEffectStart` → `Main.OnLash`.
Vanilla hit barks: a torture hit puts the 3 s `QuietMarker` on the victim (whip: second ENCH effect; other torture sources: `Classifier::MarkQuiet` from the damage hooks, cast as an SKSE task), and the `QuietDialogue` quest's silent Hit / Assault / AssaultNC INFOs (condition `HasMagicEffect QuietMarker`) win over vanilla lines such as "What are you doing?", so SkyrimNet speech is not blocked.
Torture is not aggression: the whip is WEAP `NonHostile`, and no effect on the torture spells is `Hostile` (0x813–0x815 and the copies 0x822–0x825 keep `Detrimental`). `Classifier::NoteCalm` records each torture hit (hit sink: whip or torture spell; `HandleHealthDamage`: torture-classified hits), and its `TESCombatEvent` sink stops a victim's combat (`StopCombat` + `StopCombatAndAlarmOnActor`, SKSE task) when it starts against that attacker within 3 s of such a hit, in either order. Actors already in combat are not touched. Before that, a call hook on `GetFactionFightReaction` in the victim's hit handling (SE 37672+0x187 / AE 38626+0x182, the Simple Offence Suppression site; skipped on VR or when no call opcode is there) turns a neutral victim's reaction to a Padded Whip lash or an out-of-combat torture punch (`Classifier::IsTortureAttacker`: empty hands and the unarmed rule is a torture source) into ally and sets the ref flag `kIgnoreFriendlyHits` (`Classifier::SuppressFriendHits`), so a lash or punch starts no combat at all; the flag is released 3 s after the last lash (`ReleaseFriendHits`, from the `TakeHits` native) and before every save (kSaveGame).
LLM actions are SkyrimNet YAML (`external/goodprovider.injuryengine/actions/<name>.yaml`, quest `Injury_Engine`, script `Injury_Engine_Actions`, positional params to member functions; eligibility only the native `is_in_combat`). `Torture_Target` (`TortureTarget`; not in combat; params target, type `whip|pinch|slap|pull|punch`, strikes `1..10`, capped by `max_strikes`) → whip: `Main.Lash` (PlayImpactEffect + sound) → `Main.OnLash`; other types: `Main.Torture` (optional `action.animation`) → `Engine.Hit`. Part names and source ids from Papyrus match case-insensitively (`InjuryConfig::IEquals`). `Main.External_Torture` is the API for any torture type (`External_Strike` stays whipping only). The `injury_engine.in_action` StorageUtil flag stops double counting.
Injury data and text: `SKSE/Plugins/Injury_Engine/injuries/<source>.json` (torture: `whipping`, `pinching`, `slapping`, `pulling`, `punching`, `fire`, `frost`, `shock`; health: `slashing`, `piercing`, `bludgeoning`, `burning`, `freezing`, `shocking`, `mauling`, `generic`; sexual assault later) loaded by `InjuryConfig` at kDataLoaded; the schema and an agent guide for improving them are in `injuries/guide.md`. Nothing about wounds is hard-coded any more: stage thresholds, part and region names, narration prose, healing text, bio / feels tables, Whip_Target text, overlay title and colors, setting defaults all live in those files (`manifest.yaml` still carries the dashboard schema and mirrors the defaults).
`InjuryEngine` (C++, co-saved version 5; versions 2–4 still load, keeping the damage only) tracks injury per actor, per body part, per source. Torture (model `torture`) is one value per (type, part): torture points `0..part max`, raised by hits and lowered by healing (game time, healing sources); a part counts only its largest type (health hold, overlay, stage); the points give the torture stage light / medium / severe and, inverted, the heal level high / mid / low (no separate healing range); healing a part lowers every type by one; real damage replacing torture lowers the part's maximum by one and clamps every type to it. Types land by their JSON `part_weights`. Parts: 6 main (face, arms, back, legs) plus, with setting `injury_engine.body.include_sexual_parts` (off by default, `SetIncludeSexualParts`), 5 small ones (nipples, pussy (women only), penis (men only), lips, ass hole) defined with their text in `injuries/sexual_parts.json` (not a source; its `text.<source id>` blocks are merged into each source's region text). Each part has its own max points and pick weight; medium / severe thresholds scale with the max; health capacity is the sum of the actor's active parts. Off: no new wounds there and hidden from prompts / overlay, existing ones keep healing. Hit code `fresh*100000000 + source*1000000 + mask*10 + level`. Model `torture`: `OnLash` calls `Injury_Engine_Engine.Hit(victim, "whipping")` (random body part; points drain over game time); whipping requires a Injury_Engine whip. `Classifier` maps unarmed NPC hits by an attacker out of combat (and in combat too unless setting `injury_engine.body.punch_combat_health` is on) to `punching` and the "(torture)" spell effects (MGEF 0x813–0x815, matched by form, in or out of combat; vanilla Flames / Frostbite / Sparks stay real damage) to `fire` / `frost` / `shock` (hit event, attacker, or an active-effect scan for spell ticks; only an equipped weapon makes a hit melee, an equipped spell ticks per `points_per_second`; both hands are checked, a "(torture)" spell matching the victim's live torture effect wins over the Padded Whip in the other hand, whose ignore result is used only when nothing else matches); `HandleHealthDamage` only reports health the game has already taken, so after the original call the hook gives back `amount - kept` (`InjuryEngine::RestoreHealth`, internal). Torture melee hits (punches) are stopped earlier: a call hook on `ProcessHitData` in the melee hit handler (SE 37673+0x3C0 / AE 38627+0x4A8; skipped on VR or when no call opcode is there) turns them into torture points and zeroes `HitData.totalDamage`, so a punch can't kill; Padded Whip hits are zeroed there too (no points; the lash ENCH brings the torture); `HandleHealthDamage` then only restores (no second `OnDamage`). Torture bleedout (setting `injury_engine.body.torture_bleedout`, on by default, `SetTortureBleedout`): `SyncHealth` puts an actor with torture at or below `health_link.bleedout_below` (15%) of max health into bleedout (`BleedOutStart`, SKSE task; re-sent once a second if graph bool `IsBleedingOut` is false) and lets it up (`BleedOutStop`) when health is above that again, on forget / death, or when the setting is turned off (`g_downed`, not saved); the next `SceneText` line for that victim ends with `session.json` `collapse` ("{target} collapses.", once). A hook on `ValueModifierEffect::ModifyActorValue` (vfunc 0x20, plain and dual; the AV argument is kNone, the effect's AV is the member `actorValue`) blocks "(torture)" Health ticks before they land, turns them into torture points with the real caster (`GetCasterActor`) and applies the dual Stamina / Magicka drain itself; the `HandleHealthDamage` restore covers everything else (see KNOWLEDGEBASE). `OnDamage` then blocks the game damage and turns it into torture hits (melee one hit, spells `hook.points_per_second` points per real second, melee and lashes `hook.points_per_hit` points on one part). Model `health` (everything else): `Hooks.cpp` hooks `Actor::HandleHealthDamage` (SE / AE) and `ActorValueOwner::ModActorValue` (kDamage on Health) on Character and PlayerCharacter, `Classifier` picks the source (TESHitEvent + the attacker's weapon: blades slashing, daggers and arrows piercing, maces / staves / fists bludgeoning, spell resist fire / frost / shock burning / freezing / shocking, creature attacks mauling, else `generic`; Padded Whip hits ignored) and `InjuryEngine::OnDamage` turns the health the attack takes into points (capacity 6 parts × 20 = 100% of max health, one location per attack: a weighted random part, tortured parts first; the attack stays on that part until it is full, then moves to another random part, tortured first). Real damage first replaces the torture points on its part (the hook reduces the damage so health does not drop by that part, torture points there are removed and the same health worth of real points added on the same part) and only then takes health, so a tortured actor dies only after the torture wounds are replaced (a hit big enough to fill its part can take some health first); the 10% floor applies only while torture points exist. The hook queues the hit (queued hits of one victim, attacker and source merge, and `TakeHits` releases one per key per second; a health hit also releases that victim's held hits; scripted strikes use `QueueHit` so they are gated too) and fires mod event `Injury_Engine_Injury`, which makes `Main.OnInjury` drain queued hits and sync events immediately (`DrainInjuryQueues`: `TakeHits`, `TakeSyncEvents`) then schedule the 0.2 s sync loop without resetting an already-pending update (`sync_pending`). `Main.NarrateRealHits` also runs on `OnUpdate` and narrates through `NarrateInjury`.
`NarrateInjury` registers a short-lived event on every hit as soon as the text exists (`injury_hit` / `torture_hit` types; id `health_<method>_<attacker>_to_<victim>` or `torturing_<method>_…`, re-register overwrites TTL). Torture hits also form one scene of (attacker, victim) pairs (StorageUtil parallel lists `KEY_SC_*` on the Main quest; no attacker = the quest itself): `SceneTick` (from `OnUpdate`) sends combined lines from `Engine.SceneText` (`session.json` + each source's `narration.session`): `start` for new pairs only, `again` every `torture_direct_narration_gap` (6 s) but only while the pair's last hit is at most `torture_again_recent` (1 s) old, `switch` when a pair changes method; after `torture_maximum_break` (3 s) with no hit the pair is dropped with no line; same method / mixed methods and several attackers or victims are worded into one line. Every automatic DirectNarration (torture start / switch / again, heal start / again, real hit, death) waits for SkyrimNet's reply to the last one: `ClaimNarration` opens when an audio line ended at least `REPLY_MIN_DELAY` (1.5 s) after `last_direct_time` with the speech queue empty, or after `injury_engine.narration.reply_timeout` (15 s) with no dialogue; it is a test-and-set claim (`narration_claim`, released by `DirectNarrate` / `ReleaseNarration`), so two threads can't send at once, and `SceneTick` sends at most one line per tick (switch, else start, else again). Waiting starts / switches stay pending and go out when the gate opens; the player is attacker or victim: `PurgeDialogue(true)` first; narration off: events. `DirectNarrate` stamps `last_direct_time` for every narration, External API ones included (those are never held back). Only pairs in sight (`PairVisible`) get combined start / again / switch lines. `Torture_Target` just lands its strikes through the scene. `injury_engine.narration.cooldown` no longer gates narration (heal sessions use the torture gap). Healing: a healing source (spell, staff, potion; `IsHealing`, the C++ `g_healers` entry) opens a heal session, also on an unhurt or untracked actor (start line from `heal_events.start_unhurt`, no heal map; its `g_healers` entry ends silently); passive healing (game time, regen) lowers points silently. Sync events (`SyncHealth` / `TakeSyncEvents`: heal start, pain gone, fully healed, stopped) are each a short-lived `whip_heal` event (id `healing_<method>_<caster>_to_<victim>`). The session mirrors the torture scene (StorageUtil parallel lists `KEY_HS_*` on the Main quest; caster or the quest itself): heal start (`NarrateSourceHeal`) opens it with an immediate `start` line (the `heal_events.start` lead + `HealMapText`); `HealTick` (from `OnUpdate`) refreshes it while `IsHealing`, sends an `again` line (`HealMapText`, skipped when unchanged) every `torture_direct_narration_gap` while healing was seen within `torture_again_recent`, and drops it with no line after `torture_maximum_break` without healing. `HealMapText` maps each part's torture points to its heal level from the part's largest type (`narration.heal.level.<high|mid|low>`, parts grouped by type and level). `HealSend` delivers like `SceneSend`: through the reply gate (a held start line waits in `KEY_HS_PEND` and `HealTick` sends it once the gate opens; a held again line is skipped), player caster or target: `PurgeDialogue(true)` first; narration off: a short-lived event with the healing id; out of sight: nothing. While the session is open the overlay bar is light blue and the feels prompt uses `text.feels.heal` (high / mid / low) instead of `text.feels.torture` (light / medium / severe). Sessions are exclusive per victim: a different activity closes the open one silently and starts its own as normal (a torture or real hit: the DLL drops the healer and `ClearHealBatch` closes the heal session; a heal session opening or a real (non-torture) hit: `ClearTortureScene` drops the victim's torture pairs; real damage has no session of its own). Every event is a `RegisterShortLivedEvent` (expires after `injury_engine.narration.event_ttl`); only narrations are permanent. Setting `injury_engine.healing.give_healing_hands` adds Healing Hands (Skyrim.esm 0x4D3F2) to the player.
LLM actions `Stop_Fighting` / `Stop_Fighting_by_Yielding` (YAML: in combat) / `Start_Fighting` (no combat gate; neither for the player or the dead), param `target`, in `Injury_Engine_Actions.psc` (`StopFighting`, `StopFightingByYielding`, `StartFighting`): native `AskTruce(speaker, target, false)` → `TruceDecision::Ask`; with the player as target it shows a vanilla Yes / No message box ("{name} wishes to stop fighting / yield to you. Do you accept?", Esc = No; `MessageBoxData` from `MessageDataFactoryManager`, queued with `QueueMessage` SE 51422 / AE 52271, not on VR; the callback answers through the same queue), otherwise it sends decision template `injury_engine/accept_truce` (`prompts/decisions/`, a `noul` question, API v12+; the callback copies its strings and moves to the game thread with `AddTask`) and queues `{speaker, target, accepted, yielded}` with mod event `Injury_Engine_Truce`; no API, no provider (`no_decisions_route`, latched until the next load), a request in flight or a failure = refused. `Actions.OnTruce` drains `TakeTruces` / `TruceSpeakers` / `TruceTargets` / `TruceAccepted` / `TruceYields` into `ApplyTruce`. Truce: always `Engine.StopFighting` on the speaker (the torture calm's stop, `Classifier::StopFighting`), on the target when accepted or when it fights the speaker; accepted also sets Aggression 0 on each NPC (StorageUtil `injury_engine.truce_aggression` / `truce_until`, form list `injury_engine.truce_actors` on the quest) for 24 game hours, restored by `RestoreExpiredTruces` (on load and from `Main.OnUpdateGameTime`); any accepted truce or surrender also arms the truce guard (`Engine.NoteTruce` → `Classifier::NoteTruce`, not saved, noted again on load from StorageUtil `injury_engine.truce_with`): pair-keyed (an actor may hold several), saved partner and end time set together by `Actions.GuardTruce` on acceptance only, cleared on kPreLoadGame / kNewGame; until it ends, the `TESCombatEvent` sink stops any combat start between the pair, and `Classifier::OnStoodUp` (from the bleedout release in `SyncHealth`) stands a truce actor down again when it gets up; truce stops also clear `kAngryWithPlayer`; short-lived event `injury_truce`. `Stop_Fighting_by_Yielding` (a surrender): the speaker stands down, is calmed and sheathes at once, then `AskTruce(speaker, target, true)` (template `injury_engine/accept_surrender`; the player as target gets the Yes / No box); accepted stops and calms the target too, refused leaves the target free to keep attacking; event `injury_truce`, id `surrender_<speaker>_to_<target>`. `Start_Fighting` restores both actors' Aggression, calls `Engine.ForgetCalm` (`Classifier::ForgetCalm`: drops the pair's `g_calm` / `g_combatStart` entries and releases `kIgnoreFriendlyHits`, so the torture calm does not stop a fight started right after a torture), then `StartCombat` (`ForgetCalm` also drops the pair's truce guard, `ForgetTruces` every guard of each actor, matching `RestoreAggression`); a second `AskTruce` from a waiting speaker to another target is refused at once, to the same target ignored, and a waiting request expires after 60 s; event `injury_combat`.
Killing blows: `InjuryEngine::OnDamage` remembers each victim's last real hit (attacker, health source, part, unarmed); a `TESDeathEvent` sink (`InjuryEngine::InitDeaths`, kDataLoaded; the event comes twice, the first takes the record) turns a death within 5 real seconds of that hit into `DeathText` (the source's `death` block: lead + a random `death.regions.<region>` line + a `death.soil` line by `soil_chance`; health files only) and fires `Injury_Engine_Injury`. `Main.NarrateDeaths` (from `DrainInjuryQueues` and `OnUpdate`, before `NarrateRealHits`, which skips hits on dead victims) drains `TakeDeaths` / `DeathVictims` / `DeathAttackers` / `DeathSources`: setting `injury_engine.narration.death_mode` (Direct Narration), narration on and in sight: DirectNarration (session `death`), else (Event, or not allowed) a short-lived `injury_death` event; Silent: nothing (id `death_<source>_<attacker>_to_<victim>`).
Narration text is rendered in C++ from the JSON files (`InjuryEngine::HitText`, `HealMapText`, `SourceHealText`, `ActionText`, natives of the same names), no prompt is involved. Prompt text for the LLM: `character_bio/0420_injury_looks.prompt` and `user_final_instructions/0420_injury_feels.prompt` loop over decorator `injury_engine_injuries(uuid)` (`Main.Injuries_Decorator`, `GetStateJson`), whose `look` / `feel` strings are already resolved for the actor.
Verbose logging (`injury_engine.debug.verbose_logging`, off by default): `ApplyPluginConfig` passes it to `SetVerboseLogging` (spdlog `debug` level in `Injury_Engine.log`) and gates `Main.Verbose` / `[v]` traces in `Papyrus.0.log`; costly messages sit inside `if verbose_logging`.
